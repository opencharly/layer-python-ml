# 2026.327.0938 — fix(candy)!: the CUDA substrate belongs to the box, not to this candy

## Summary

`require: layer-cuda:v2026.323.0252` was target-blind: it asserted the GPU stack for **every** consumer of this candy. A CPU box therefore dragged a toolkit it cannot use, and a CDI pod re-composed a substrate its base had already applied. This removes the entry and says where the substrate belongs, following the precedent `opencharly/pod-comfyui#24` set (opencharly/layer-cuda#34, item 6).

The GPU boxes that need it base on `podcdi.pod-cdi`, which composes `layer-cdi → layer-cuda`, so the toolkit is still present exactly where it is real.
